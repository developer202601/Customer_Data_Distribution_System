# Fix OMNI API to Use GET Instead of POST

## Problem
The original curl command uses `--request GET`, but `OmniBillPaymentService::fetchBillPayment()` currently uses `Http::post()`. This causes the API to reject the request.

## Fix
Change `->post()` to `->get()` and pass parameters as query string instead of form body.

## File to Modify
`app/Services/OmniBillPaymentService.php` — lines 43-52

## Current Code
```php
$response = Http::timeout($this->timeout)
    ->withHeaders([
        'Content-Type' => 'application/x-www-form-urlencoded',
    ])
    ->asForm()
    ->post($this->apiUrl, [
        'telephoneNo' => $telephoneNo ?? '',
        'accountNo' => $accountNo ?? '',
        'secretCode' => $this->secretCode,
    ]);
```

## New Code
```php
$response = Http::timeout($this->timeout)
    ->withHeaders([
        'Content-Type' => 'application/x-www-form-urlencoded',
    ])
    ->get($this->apiUrl, [
        'telephoneNo' => $telephoneNo ?? '',
        'accountNo' => $accountNo ?? '',
        'secretCode' => $this->secretCode,
    ]);
```

## Changes
- `->asForm()` removed (not needed for GET)
- `->post()` → `->get()`
- Parameters moved from POST body to GET query string (same array structure)

## Validation
- Verify the API call matches the original curl: `GET url?telephoneNo=&accountNo=&secretCode=`
- Check that the API response is still parsed correctly
